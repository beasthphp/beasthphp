**Backend audio pipeline combining Python and C++** — FastAPI handles MP3 uploads, a background worker validates media with FFprobe and transcodes with FFmpeg, and a C++ HTTP server serves processed audio for seekable playback.

`C++17` `Python` `FastAPI` `FFmpeg` `FFprobe` `CMake` `HTTP Streaming`

**[View repository →](https://github.com/beasthphp/distributed-audio-platform)**
